## 1. 确定性内核抽取方案.md —— 当年诊断的三大病，Java 版全解

| 当年的病 | Java 版现状 | 判定 |
|---|---|---|
| P1（致命）模拟 RNG 与 `Math.random` 共用一条流 | `SeededRNG` 主种子 + SHA-256 派生流；simRNG/fxRng 严格隔离；块光/群系/巨构全部"零 RNG"纪律 | ✅ 彻底解决 |
| P2 模拟反向依赖表现层（sim→render） | `core/**` 纯 Java 无 DOM 无 GL；渲染独立 `render/lwjgl`；仿真 headless 可跑（门禁证明） | ✅ 彻底解决 |
| P3 全局可变状态 + DOM 依赖 | 状态对象化（World/Simulation/Player）；无 DOM | ✅ |
| 阶段 D：序列化/版本兼容/云存档 | `chunkEdits` 快照 = 内存态存档雏形；**落盘存档/版本兼容/云 ❌** | 🔶 |
| CI 护栏（零偏移人治→法治） | **17 道门禁 + `build_runner.py` 一键全跑**——比当年设想的"平衡护栏"强一个量级（还含指纹隔离/零 RNG/可达性证明） | ✅ 超额 |

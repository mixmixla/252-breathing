## 二、当前底账（规模与预算）

- 渲染层：Game 1747 行 / Chunk 410 行；每帧 draw call ≈ **11-45**（视锥剔除后）；脏块重建预算 4/帧；VP/视锥零分配。
- 核心层：World 829 行 / Player 450 行；92 系统在线；滑动窗口 96×112×96。
- 已知短板集中区：**水中体验缺失**（世界 1/4 是湖）、**夜间光照平面化**、**挖掘/放置无指向反馈**。

## 四、复审（2026-09-11 · 用户质询"能学的为什么不学"后逐条重确认）

### 4.1 纹理图集 —— ❌不学 → ✅**翻案：学（立项）**
- **原判理由的漏洞**："身份差异"不成立。我们的身份是**不加载外部素材、一切程序化**——这**不妨碍**程序化生成图集：启动时用色板 + 固定种子噪声在 CPU 上烘焙一张图集（草=绿底短条纹、石=灰底斑点、木=纵纹、水=波纹……），网格加 UV、shader 采样。零素材资产、纯确定性，比"每体素 ±6% 明度颗粒"的细节丰富一个数量级。
- **为什么值得**：顶点色是**每面单色**，无论怎么调颗粒都有塑料感——这才是用户"色块缺纹理材质"不满的**根源**（颗粒只是缓解）。图集是根治。
- **成本（诚实版）**：顶点格式 40→48 字节（加 UV，Chunk/Game/Silhouettes 所有发射点适配）+ 烘焙器 ~150 行 + shader 采样改造。风险中。
- **裁决**：**学。P1 执行层大项，单独立项**（与 LAMP 块光并列）。

### 4.2 挖掘进度裂纹 —— ❌不学 → ✅**翻案：学（变体）**
- **原判理由的漏洞**："ARPG 即时挖是节奏设计"——但即时挖其实**削弱 P2**：世界没有"硬度"反馈（石头和土一样一碰就碎），重量感少一块。
- **学的变体**（不是照抄 MC 的工具系统）：**按住挖 + 每方块硬度 0.2~0.8s + 裂纹进度渲染**；不引入镐子/工具等级（保 MC 极简 P4）。时长参数化，本机手感验收调；嫌慢随时调回即时档。
- **成本**：低-中（输入层按住状态 + 硬度表 + 裂纹色阶叠加在交叉面/立方面上）。漂移：`editBlock` 事件语义不变 → 零漂移。
- **裁决**：**学。归入 P2 手感批次**。

### 4.3 LOD / 遮挡剔除 —— 二次复审（2026-09-11 下午 · 用户再质询"真的不能学吗"）
- **LOD：判定升级为"学不了=不该学"**——**MC 本体根本没有 LOD**（`REFERENCE.md` 全文 0 处提及；MC 的远处简化=视距上限+雾，Sodium / Distant Horizons 是**模组**不是本体）。我们已有等价且便宜一个数量级的替代：距离雾 + 巨构剪影（§9 P1）。学 LOD = 学模组不学本体 = 无收益。
- **遮挡剔除：从"维持不学"改为「⏸ 挂起（SUSPENDED），量化触发即排期」**——不是被掩埋，是有唤醒条件的休眠任务：
  - **当前账本（实测口径）**：窗口 96×96 → 36 chunk，视锥剔除后常态 6-12 draw、70-180 万顶点/帧——现代 GPU（含集成）1-2ms，**GPU 路径不是瓶颈**（用户卡顿报告均指向 CPU 侧 meshing，已由重建预算修复）。
  - **可学形态（触发后第一刀）**：轻量山地遮挡——`terrainHeightField` 高度场启发：站在谷底时视线方向上被前方高点完全遮蔽的 chunk 跳过绘制，~40 行、零数据结构；第二刀才是 MC 的 visibility graph + BFS（触发光：室内大空间）。
  - **唤醒触发器（写死）**：① F3 观测 draw call 常态 >60 或顶点/帧 >500 万；② 视距默认 >800；③ 窗口 >256×256；④ 引入室内大空间。触发即排期，走零漂移门禁。
  - **【已落地（2026-09-11 下午）】**：用户裁决**主动制造前置条件**——窗口 96→**160**（36→100 chunk）+ 视距 96→128，规模触发成立 → 随即落地**轻量山地遮挡第一刀**：`Chunk.maxY` 列顶包络（rebuild 顺带算，玩家拆山自动更新）+ `Game.terrainOccluded`（沿相机→目标块顶每 16 格采样，视线判定线上移 2 格，中段被截即遮挡；近 64 格豁免）+ F3 加 `DRAW x/100  FACES yk  OCCL z` 观测。自测四场景 PASS（开阔可见/立山遮挡/近距豁免/山顶越线）。gate=PASS（21 处 `_EXIT=0`、四道基线指纹逐字节不变——门禁小世界不受窗口参数影响）。第二刀（MC visibility graph）仍挂触发器：室内大空间场景。

### 4.4 生物群系 —— ❌后置 → ✅**翻案：学（立项，成本被高估）**
- **原判理由的漏洞**：我把"学 MC 的**完整群系系统**"（气候 API、BiomeSource、群系结构表）和"学它的**表层视觉层**"划了等号——前者确实是大工程，但我们要的只是后者。
- **学的变体**（MC `SurfaceRules` 思想，REFERENCE.md §3）：地形**高度公式不动**，只加两条独立确定性噪声（温/湿，cellHash 派生，粗尺度）→ 查 4-6 格**表层选择表**：雪原（SNOW/ICE 表层）、干旱（SAND/CLAY）、草原（现状）、花海（花密度分区）……表层方块选择是 `generateChunk` 里一个查表函数。
- **为什么值得**：P3 探索回报的核心——**走远=看到不同的世界**；P1 的"活"感大来源。这是巨构之后"远方有未知"的第二根柱子。
- **成本（诚实版）**：低-中（表层查表 + 植被密度分区）。漂移：mat 变 → 有意重基线（流程成熟，上周刚走过）。
- **裁决**：**学。立项级**。

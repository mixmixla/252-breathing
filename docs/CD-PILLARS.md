# CD-PILLARS · 核心创意支柱（创意总监裁决 · 唯一真理源）

> **性质**：创意方向文档（creative-direction）。由 `creative-director` 在 2026-09-10 经用户裁决确立。
> **裁决**：保留项目既有的「4 支柱」命名（世界活着 / 手感 / 探索回报 / 成长可见）作为**核心创意支柱**，但升级为可证伪 + 带设计测试的创意断言；原「4 支柱」作为*交付验收清单*的语义并入 **G1–G5 出门闸门**；Art Bible 的 4 视觉支柱降为**美术执行层**，从属于 P1。
> **用途**：今后任何部门冲突（设计 vs 叙事 / 美术 vs 音频 / 范围 vs 产能）且「改变了游戏身份」时，以此文件裁决。

## 0. 为什么需要这份文档（三层防混淆）

项目里长期飘着三套同名不同义的东西，必须各归其位：

| 层 | 内容 | 它回答的问题 | 权威文件 |
|----|------|------------|---------|
| **A · 创意支柱（本文）** | 世界活着 / 手感 / 探索回报 / 成长可见 | 游戏**是什么**、情感承诺、冲突裁决源 | `docs/CD-PILLARS.md`（本文件） |
| **B · 交付验收闸门** | G1 手感 / G2 世界活着 / G3 留存 / G4 性能 / G5 无回归 | **何时可出门**、必须交付什么 | `orchestration/task_board.json` + `VALIDATION_CHECKLIST.md` |
| **C · 美术执行层** | Grounded / Atmospheric / Breathing / Readable | 视觉**如何落地** | `docs/ART_BIBLE.md` |

**铁律**：C 从属于 A（视觉支柱是 P1「世界活着」的呼吸感执行）；B 是 A 的可验收投影（P1↔G2、P2↔G1、P3/P4↔G3）；A 是唯一身份真理源，B/C 不得反向定义创意。

## 1. 核心幻想与差异点（Core Fantasy & Hook）

- **Core Fantasy（情感承诺）**：你身处一个**不靠你也能运转、且会因你而改变并被记得**的确定性涌现世界——你既是建造者，也是被世界铭记的守护者。
- **The "and also" 测试**：「它像 **Minecraft**，AND ALSO 世界是一台确定性涌现仿真，你的每一次击退 / 建造都真实改写并*记住*了世界（Souls 式 stakes + Zelda 式探索回报）。」若去掉「确定性涌现 + 因你而变且被记得」，这游戏就退化成又一款体素建造——这正是本作的不可让渡差异点。
- **定位地图（Positioning Map）**：
  - 横轴：手工关卡 ←→ 涌现活世界（本作极右：81 系统确定性涌现）
  - 纵轴：休闲建造 ←→ 硬核动作（本作中上：中速可学，非删档魂）
  - 邻居：Minecraft（建造，无涌现叙事）/ Valheim（生存建造+战斗，弱涌现）/ Terraria（2D 涌现）/ Elden Ring（动作演出，无建造）/ Zelda（探索回报，手工世界）。本作独占「**高涌现 × 中速动作 × 因你而变的记忆**」象限。

---

## 2. 目标美学（MDA 排序）与玩家心理

优先级（高→低）：**Discovery（探索）> Sensation（感官/呼吸感）> Challenge（中速 mastery）> Expression（创造）> Submission（放松）**。

与 Self-Determination Theory 对齐，确保美学目标与系统交付的心理需求一致：
- **Autonomy（自主）** ← P4 创造 + P3 探索（玩家选怎么建、去哪探）
- **Competence（胜任）** ← P2 手感（中速可学、翻滚可救场、养成可见成长）
- **Relatedness（联结）** ← P1 世界活着（村志记得你——弱相关但存在，避免纯孤独沙盒）

> **Ludonarrative Consonance（机制-叙事一致）铁律**：若叙事说「每一份守护都被记得」，机制就**必须**让 `villageMemory` 真的被玩家看见（NPC 对话 / 村志浮层），否则玩家会感到无法言说的割裂。P0-B（无 NPC/对话读者）曾让叙事支柱空转，是为前车之鉴。

## 3. 四大创意支柱（可证伪 + 设计测试）

### P1 · 世界活着（The World Lives）
- **核心幻想**：你身处一个不靠你也能运转、且会因你而改变的确定性涌现世界。
- **内部张力（正是艺术所在）**：*自发呼吸*（树长/火烧/水漫/兽群迁徙，无玩家也演——「活的沙盒」证明）vs *因你呼吸*（击退→繁荣→蓝图解锁→村志记得你——「游戏」证明）。
- **设计测试（可证伪）**：一个试玩者能否**不靠提示**，指认「这一处世界变化是因为我」？（直接投影到 G2 闸门）
- **裁决权重**：当「自发涌现好看」与「因你而变清晰」冲突时，**优先后者**——USP 的落点是 G2「世界因你而改变」，好看但不可指认的涌现退居次席。
- **约束部门**：systems（涌现保活 + 接玩家杠杆）、narrative（村志/对话读者）、render（呼吸感：AO/风动/接触阴影，见 Art Bible）。

### P2 · 手感（Weighted Feel）
- **核心幻想**：每一次挥击 / 跳跃 / 闪避都有可读前摇 · 可感命中 · 明确后摇与后果（ER 式演出 + Souls 式 stakes）。
- **内部张力**：重量感（前摇/后摇/顿帧）vs 流畅度（Zelda 快）。本作定位**中速可学**——前摇可读但翻滚可救场，死亡有代价（掉魂）但不删档。
- **设计测试（可证伪）**：每次攻击是否有①可读前摇 ②可感命中（顿帧/击退/屏震）③明确后摇？死亡是否「有意义」（掉魂/重生代价而非秒回满）？
- **约束部门**：game-designer（战斗 kit / 攻击意图）、art/ui（hitstop/knockback/屏震/描边）、audio-director（命中音/顿帧静默——待建）。

### P3 · 探索回报（Earned Discovery）
- **核心幻想**：能力→门禁→折返→回报的塞尔达闭环；世界把奖励藏在「需要新能力才够得着」之处。
- **内部张力**：探索回报 vs 引导强度。本作取**弱引导**（环境暗示 + 祭坛光柱），保发现感、降劝退。
- **设计测试（可证伪）**：每个新能力（GLIDE/DASH/BOMB 等）解锁后 **60 秒内**，玩家能否用它到达一个此前到不了的点 / 秘密？
- **约束部门**：game-designer（祭坛/能力门禁/可交互物）、systems（ShrineSystem 觉醒）、ui/narrative（弱引导提示）。

### P4 · 成长可见（Visible Growth）
- **核心幻想**：你的投入（建造 / 战斗 / 魂锻）被世界与角色**可见地**承认——MC 式极简「挖/放」操作，后果涟漪进活世界（繁荣 / 蓝图 / 村志 / 属性成长一眼可读）。
- **内部张力**：成长深度 vs 上手门槛。保 MC 极简，深度靠「营造→繁荣→蓝图」链与 build/配装，而非复杂 UI。
- **设计测试（可证伪）**：新手 **60 秒内**能否造出有意义之物并看到世界（繁荣+ / 结构生成 / 村志）对此的认可？角色成长（LV / 属性 / 装备）是否在 HUD 一眼可读？
- **约束部门**：systems（build/prosperity/蓝图）、player（养成/魂锻）、ui（HUD 层级）、narrative（村志认可）。

> 四支柱干净覆盖用户五点愿景：建造=P4，ER 战技=P2，塞尔达=P3，世界活着=P1，UI/养成为横切（P2/P4 共需）。

## 4. 反支柱（Anti-Pillars · 本作不是什么）

每条「不」都在保护一条「是」，防范围蔓延：
- **不是纯沙盒**（无目标的自由建造）——世界必须因你而变且被记住（护 P1/P4）。
- **不是硬核魂**（死亡即删档）——中速可学、翻滚可救场、掉魂不删档（护 P2 可达性）。
- **不是强引导开放世界**——弱引导保发现感（护 P3）。
- **不是写实画风**——MC 明亮饱和 stylized（护 P1 呼吸感 + Art Bible）。

## 5. 支柱冲突裁决示例（Pillar Conflict Resolution）

| 冲突场景 | 裁决（依据） | 理由 |
|---------|------------|------|
| 某涌现系统很美但玩家无法归因（自发≠因你） | 降级为氛围，不占叙事资源（P1 裁决权重：优先「因你而变清晰」） | USP 落点是 G2 |
| 加一个超帅战技但前摇长到新手劝退 | 砍前摇或加翻滚取消（P2 中速可学） | Competence > Sensation 单点 |
| 新能力解锁但附近无秘密可探 | 回退或补秘密点（P3 设计测试 60s） | 否则探索回报落空 |
| 复杂装备 UI 能加深 build 但抬高门槛 | 深度走「链」不走「UI」（P4 张力） | Autonomy 优先于系统炫技 |

## 6. 范围裁剪优先级（Scope Cut · pillar proximity）

| 优先级 | 类别 | 动作 |
|-------|------|------|
| 绝对保护 | 即是支柱本身（P1 世界因你变 / P2 中速手感 / P3 探索闭环 / P4 可见成长） | 不可砍，砍=换游戏 |
| 简化 | 服务支柱但成本高（如多武器多战技 → 先 1–2 种保 P2 手感） | 留核心 20% 交付 80% 支柱值 |
| 次切 | 服务支柱但性价比低（如昼夜视觉反馈） | 延后，不阻断出门 |
| 先切 | 不服务任何支柱（曾规划的过度文明/经济系统若无解谜牵引） | 直接砍或休眠 |

## 7. 部门委派（Delegation Map）

- `game-designer`：P2 战斗 kit / P3 能力门禁与可交互物 / P4 build 链（在创意约束内做机械设计）
- `art-director`：C 层视觉执行（Art Bible 已从属 P1 呼吸感；AO/天空雾/风动/接触阴影服务 P1）
- `audio-director`：P2 命中音/顿帧静默（待建，须服务手感权重）
- `narrative-director`：P1 村志读者 / P3 弱引导叙事（须守 Ludonarrative Consonance）
- **升级靶**：任何「改变游戏身份」的决策 → 回本文件裁决；产能 vs 创意意图碰撞 → creative-director 仲裁。

## 9. ADR 元信息

- **Context**：EVAL-1/2 评审后，项目已从「搬系统」转向「做可玩闭环」；但「4 支柱」「视觉支柱」「G1–G5 闸门」三套同名概念混淆，部门无统一裁决源。用户要求梳理核心创意支柱。
- **Decision**：保留既有 4 支柱命名作为创意核心并升级为可证伪断言；厘清三层（创意/交付/美术）；本文件为唯一真理源。
- **Alternatives Considered**：
  - *重铸 4 支柱*（会呼吸/有重量行动/应得探索/看得懂创造）——更贴「身份」语义，但用户选择保留既有命名以保连续性。
  - *更紧 3 支柱*（创造并入世界）——更聚焦但弱化用户明确要的 MC 建造辨识度，否决。
- **本次裁决**：用户拍板「保留现有 4 支柱 + 落正式文档」。创意总监遵从——命名连续性优先于措辞优雅。
- **Cascade**：Art Bible 加「从属 P1」声明；orchestration 黑板加 `creative_pillars` 行；event_log 加 `[CD-PILLARS]`；记忆日志追加。
